# My Personal Space

## Project Description

My Personal Space is a Flutter application developed as part of an academic activity. It demonstrates basic Flutter functionalities, navigation between screens, forms, date selection, and calculations.

## Features

The application includes three main features:

1. **Age Calculator:** Allows users to select their birth date and calculate their age.
2. **BMI Calculator:** Calculates the Body Mass Index using the user's weight and height.
3. **Zodiac Sign:** Identifies the user's zodiac sign based on their birth date.

## Technologies Used

- Flutter
- Dart
- Visual Studio Code
- GoRouter
- Material Design
- Flutter Localizations
- Intl

## Navigation

The application uses GoRouter to navigate between the home screen and the three main features.

## Installation and Execution

To run this project locally:

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install the dependencies:

```bash
flutter pub get
```

5. Run the application in Google Chrome:

```bash
flutter run -d chrome
```
